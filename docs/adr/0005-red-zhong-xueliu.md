# ADR 0005：红中血流（5023）的赖子、红中杠与补充约定

状态：**已废弃**（2026-10-18）。项目收敛为单机立直，四川后端已删除；最后完整实现见提交 `a469df1`。另记：原客户端大厅没有 5023 入口，只有调试菜单 `SROptions.TestEnterSicHongZhongXueLiu`。原状态：采用，仅适用于5023红中血流。5021/5022 仍按 [ADR 0004](0004-sichuan-scoring-clarifications.md)；本 ADR 未覆盖的计分、支付、荒牌与血流局序同样沿用 ADR 0004（含普通血流补充约定）。

## 依据与范围

原文来自 `mockjs/sichuan_catalog.mjs` 中的 5023 条目：`CommonRulesCfgTb` 502301–502307、`CommonCNYiCftTb` 52 条（41 条展示）、`MatchSeparateCfgTb` 6 个房间。明确的原文规则：108 张序数牌加 6 张红中赖子共 114 张；可换任意三张手牌；保留定缺；血流胡后继续；红中赖子不能做将牌单吊；红中打出算杠、不收底分、可触发杠上开花和杠上炮、不触发抢杠胡；番型表含红中杠 2/4/6/8/10/12 档、杠上炮 2 倍、红中金钩钓 16 倍（只能自摸）。

客户端静态逆向（wasm 符号）确认：`SetLaiZiCards/IsLaiZiCard` 读取 `NtfGameStart.guiCards`；`SiCMGPlayingCardState_OnPlayCard` 对赖子只要求 `remainDuiCardNum > 0`，然后走普通出牌；换牌状态在 gameType=5023 时调用任意换牌分支。没有独立的红中杠协议消息或动作枚举。以下凡原文未写明的部分均为**本地约定**。

## 决策

1. **实体与协议**：红中实体为 451..456，展示牌种 450；`NtfGameStart.guiCards=[450]`，`changeCardRule=2`（RenYiHuan）。客户端用 `ReqPlayCard{action: Normal, card: 红中}` 打出红中，服务端裁决为红中杠；下行依次为 `NtfPlayCard(Normal)`、无人可抢的 `NtfQiangCardEnd`、牌尾补牌 `NtfSendCard`。
2. **赖子**：红中只在暗手中作万能牌，可替任意非缺门序数牌组成顺子、刻子、将或七对对子；不能被碰、杠，也不能进入副露。根、龙七对的“四张”只按真实同种四张计，赖子不凑根。红中不属于任何花色，不构成花猪。
3. **单吊限制**：和牌张是序数牌、它与一张红中组成将、且该牌种在暗手中只有和牌这一张时，该分解无效（七对同理）；若存在其他合法分解仍可和。两张红中成将不受限制，这正是原文“红中金钩钓”（四副碰杠后剩一张红中、自摸第二张红中，只能自摸）。听牌/查大叫只列可荣和的序数牌；手里只剩单张红中的金钩钓形态没有序数牌等待，荒牌时按未听处理。
4. **红中杠**：轮到本人、牌墙仍有牌、且手中已没有定缺花色时，可打出任意一张红中算杠。不开抢牌窗口、不收底分、没有呼叫转移可转的收入；从牌尾补牌，补牌自摸计杠上开花，补牌后打出的牌被荣和计杠上炮。牌墙摸完后红中不能再杠；此时若手里只剩红中，才允许把红中当普通弃牌打出，且没人可以碰杠胡这张红中。
5. **红中杠倍数**：和牌时按本人本局已打出的红中杠总数 n 取原表第 n 档（2/4/6/8/10/12 倍），不是逐张乘 2；血流多次胡牌时每次按当时的累计张数计。
6. **胡后锁牌**：与 5021 相同；已胡者摸到红中时只能自摸或红中杠（无牌可补时摸切）。
7. **换三张**：任意三张实体牌，不要求同花色；AI 换牌只选同花色三张且不送出红中。
8. **房间**：免费场原表 `topBei=0` 语义不明，按其他玩法免费场的 128 倍执行；其余房间按原表 128/256。5023 原文没有“血流封顶”累计输分上限，因此不设整局输分上限。
9. **AI**：只读本人视图。只有去掉某张红中后的向听不差于最佳普通出牌时才主动红中杠；向听估算把每张赖子视为推进一步，仅用于排序，听牌判断仍用实体等待复核。

## 后果与未验证项

- 未在原 Unity 页面观察到红中杠的实际演出（AI 极少主动红中杠）；`NtfQiangCardEnd` 的插入与 `canPlayActions` 合并（红中杠与普通出牌都映射为 `Normal`）只有 Node 回归，没有浏览器证据。
- 451..456 是按既有实体编码推定的 ID，客户端只直接证明了展示牌种 450 与 `guiCards` 读取路径。
- 番型（连六、双同刻、三连刻、全双刻、一色双龙会、九莲宝灯等 5023 专有项）按原文字面实现，牌例回归有限。
