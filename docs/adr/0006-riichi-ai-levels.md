# ADR 0006：立直 AI 分级（低级 / 中级 / 高级）与房间路由

状态：采用，适用于立直麻将（四麻、三麻）。

## 背景

旧 `basic` 是独立的向听/受入启发式，与高级框架分离。用户本轮确认：高级保留完整能力，从同一框架裁减思考形成中级，再裁减形成低级；不能以错误或违规动作制造难度差。旧 basic 决策路径已删除，旧版本对照须显式加载独立基线引擎。

## 决策

1. **分级与路由**：`GameEngine` 接受 `aiLevel`（整桌）或 `aiLevels`（按座位），取值 `basic` / `intermediate` / `advanced`，缺省或未知值为 `intermediate`。服务端段位战御龙间（`roomID=4`）用 `advanced`；乘风（3）用 `intermediate`；启航/逐梦（1/2）用 `basic`；一局战、默认及未知房间用 `intermediate`。真人托管与断线接管使用同桌难度。
2. **三档共用框架（`mockjs/riichi_ai_policy.mjs`）**：对每个合法弃牌计算期望值
   `EV = max(和牌概率 × 预计打点 − 后续放铳暴露, 弃和基线) − 本张放铳概率 × 威胁打点`。
   - 和牌概率：按向听阶段逐巡推进（本阶段用实测受入，一向听用进听后的平均听牌受入，更远阶段用默认受入），计入他家打出放铳的机会和他家先和导致本局结束的存活率；
   - 预计打点：宝牌/赤宝/拔北、役牌刻子与对子、断幺（门清按幺九张数折算）、一色、门清立直期望，开门且无役路线计 0；
   - 放铳：沿用公开信息危险度（现物、筋、壁、字牌见张），按立直/两副露威胁的估计打点折算；
   - 顺位：中级在 All Last 领先时放大放铳代价、压低打点价值，末位反之；低级省略该修正，高级另用顺位效用；
   - 无威胁时不为打点退向听；有威胁时所有合法牌均可作为弃和候选。
   三档均用 `calcWin` 对每张待牌计算立直/默听的真实点数；中级在 All Last 领先 8000 以上且默听有役时倾向默听，低级省略此顺位修正。
   - 鸣牌：吃、碰、大明杠与跳过同用期望值比较——吃/碰取鸣后立即打出的最佳弃牌期望（含食替禁止），大明杠取补牌前的手牌展望并按 1.2 倍计入新杠宝；跳过取当前 13 张的进攻/弃和展望。开门仍须先通过原有的成役路线检查，大明杠仍须满足原有杠条件。
   - 暗杠/加杠：原有杠条件之外，押引模型判定应弃和时不杠。
   - 拔北：三档均仅在拔北不增加向听数时拔出，保留国士必需牌、唯一雀头等关键北牌。未比较完整的保北/拔北期望，也未单独估计抢北风险。
3. **高级**：在中级排序的前 8 个候选中，对打出后一向听以内的候选做摸牌期望搜索：枚举进听牌，为每张进听牌选最佳听牌打法，按待牌逐张用 `calcWin` 算真实役种与点数，无役待牌不计入有效受入；仅在门清、点棒足够且预计余牌允许时计入未来立直。一次 `aiTurn`（立直/押引/弃牌共用）或 `aiClaim`（各鸣牌选项均分）上限为 1500 次 `calcWin`、120000 单位可选牌效工作量（向听=1、等待=35）。必需基础扫描另记 `baseWork`，不是时间硬上限；耗尽时确定性回退封闭式估值，未搜索候选不得凭粗估反超已搜索候选。牌形缓存仅限单次决策，打点缓存区分赤宝实体、路径假想摸牌与弃牌，假想摸入会扣减剩余枚数。高级另加：
   - **读牌模型**（`mockjs/riichi_ai_read.mjs`）：含门清国士先验，区分单面/十三面振听，拔北不排除国士；其他副露/暗杠排除。只用公开信息逐家估计听牌概率（立直=1；副露数、巡目、摸切/手切与牌序推断）、威胁打点（立直、宝牌、副露染手/断幺/对对线索）和逐张放铳概率——按两面/嵌张/边张/双碰/单骑的待牌形状权重（1 / .19 / .27 / .43 / .37）与可见枚数组合，现物、立直后通过牌、同巡通过牌按振听处理为安全。多家威胁分别计算后合并。
   - **弃牌估值**：放铳损失取读牌结果；弃和按手中最安全牌序列估值；进攻计入后续每巡摸切暴露（未来威胁按巡目增长）；All Last 用顺位马把得失换算为顺位效用；末盘计形式听牌料。
   - **牌效**：二向听候选用二阶牌效（进一向听后的平均听牌受入，最多 5 个候选）；荣和受入按字牌、幺九、筋引掛和宝牌对他家打出概率加权；振听待牌只计自摸，候选弃牌本身进入牌河后再判振听。
   - 立直/默听用读牌暴露比较，均不如弃和时交给弃牌评估；立直见逃永久振听只计自摸。三麻真实打点保留原符数，复用引擎补番计分叠加拔北和公开北宝牌指示牌，不读取里宝牌。
   - 当前不启用默听等待改良的独立搜索路线。
4. **能力裁减**：低级使用封闭式牌效/打点/基础防守与押引，不做待牌质量细化、顺位修正或高级搜索；中级恢复一向听待牌质量细化与顺位缩放，仍不做高级读牌或摸牌期望搜索；高级保留完整读牌、二向听二阶牌效和一向听以内搜索。三档共用整次决策预算、关键北保护、真实符数/拔北估值与决策内牌形缓存，耗尽时确定性回退。具体回归见 `test/ai-levels.test.mjs`。
5. **公平**：只读自家手牌和公开信息（牌河、副露、宝牌指示牌、分数、余牌数），不读对手暗手、牌山、岭上和里宝；回归测试对这些字段设读取陷阱。

## 后果与未验证项

- 参数仍为经验值；不模拟对手后续行为，不是完整麻将求解器。二阶牌效覆盖二向听，真实打点搜索只覆盖一向听以内；吃/碰后的弃牌可调用高级搜索。
- 国士先验、押引、顺位效用、荣和权重等是公开信息启发式，不能把其结果当作真实放铳概率。对人类牌风、半庄强度、本轮 Unity 界面体验均未验证。
- 拔北目前只防止直接退向听，并非完整保北/拔北收益比较；暗杠/加杠仍沿用条件与押引约束。
- 当前保留的探索性增强不具备显著优于旧版的证据；下一步应先做三麻独立种子大样本验证，不用这 30 个种子反复调参后当作独立验收。
- 新 `basic` 已用于启航/逐梦，与历史独立启发式同名但不是相同策略。历史强度对照不能直接外推到新三档。
